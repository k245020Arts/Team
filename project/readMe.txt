---------------------------概要--------------------------------

ジャスト回避を主体とした戦闘アクションゲームとなっています。

〇開発時期　2025年6月 ～　2026年1月

6月から9月まではプレイヤーの基本アクションを中心に一人で制作をしていき
10月から新しくメンバーを入れて、本格的に敵キャラクターを入れていき、バトル面を作り始めていきました。

〇開発人数

プログラマー2人
デバッカー1人
でやってきており、自分がチームリーダ、プログラマーの統括をしています。


〇開発環境、動作確認環境
　　・OS  Windos11
  　・13th Gen Intel(R) Core(TM) i7-13620H (2.40 GHz)
  　・GPU NIDIA GeForce RTX 4050  
  　・メモリ　16GB　


〇担当箇所
プレイヤー周り
ボスの行動選択AI
データの外部化(プレイヤー、ステージ、ボス)
カメラの設定とカメラシーンツール作成
全体の設計
CommonフォルダやComponentフォルダの汎用的に使えるクラスの生成

〇こだわったポイント
どのオブジェクトでも汎用的に使用できるStateパターンやコンポーネントの実装
カットシーンのカメラを外部データ化をし、一つのクラスでまとめられるようにしました
ボスの攻撃をゲーム内で追加できるようにした、それらを一つのクラスに集約させた
プレイヤーの攻撃力などをゲーム内で調整出来るようにした

---------------------カメラツールの開き方--------------------

SKY WARS DEBUG.exeを開き
Tabキーを押すとカメラのツール画面が出てきます。
主に演出用のカメラを作りたいときに使用します。
そこでデータをセーブするとプログラムの知識がなくてもカメラの設定が行えるようになっています。

ソースファイルの場所はCutSceneCamera.cpp.hとCameraEditorGui.cpp.hに中身は書いてあります。

---------------------デバック画面の開き方--------------------

SKY WARS DEBUG.exeを開き
Zキーを押すとデバックの画面が表示されていき、パラメーターや値の調整が出来るようになっています。

--------------------プレイヤーパラメータ調整ツールの開き方--------------------

通常版でもDEBUG版でもどちらでも開ける
コントロールキーを押すと画面が開き、攻撃ごとにパラメーターを調整出来るようにしています。
Reloadボタンを押すと値を変えたところを即時反映が可能。
Saveボタンを押すとjsonファイルにデータが保存されるようになっています。

--------------------------------------------------------------------------------

--------------------ボスパラメータ調整ツールの開き方--------------------

通常版でもDEBUG版でもどちらでも開ける
F2キーを押すと画面が開くようになっています。
Add系ボタンは攻撃とか投擲物の追加が可能になっています。
Saveボタンを押すとjsonファイルにデータが保存されるようになっています。

--------------------------------------------------------------------------------

〇操作説明

このゲームはXBoxコントローラーで操作するのを推奨しています。

-----------------------XBoxコントローラ-----------------------


<<<タイトル画面>>>

Aボタン : ゲーム開始

左スティックを右側に移動させるとステージ変更が出来ます。
今はステージモデルとBGMしか変わっていません。

--------------------------------------------------------------

<<<ゲームプレイ画面>>>

左スティック : プレイヤー移動


--------------カメラロックオンモードでないとき--------------

右スティック : カメラ回転
右スティック押し込み  :  カメラロックオンモード開始


--------------カメラロックオンモードの時 --------------------

右スティック : ターゲットの対象を変更
右スティック押し込み  :  カメラロックオンモード解除

---------------------------------------------------------------

Aボタン : 回避
Bボタン : 攻撃
Xボタン : 必殺技ゲージがたまったら必殺技が発動
Yボタン : チャージ強攻撃

敵の攻撃が来るときに回避ボタンを押したらジャスト回避が発動できます。


---------------------------キーボード---------------------------

<<<タイトル画面>>>

Pキー : ゲーム開始

--------------------------------------------------------------

<<<ゲームプレイ画面>>>
Wキー : プレイヤーが前に移動

Aキー : プレイヤーが後ろに移動

Sキー : プレイヤーが左に移動

Dキー : プレイヤーが右に移動


--------------カメラロックオンモードでないとき--------------

上キー : カメラが下に回転

下キー : カメラが上に回転

右キー : カメラが右に回転

左キー : カメラが左に回転

スペースキー  :  カメラロックオンモード開始

--------------カメラロックオンモードの時 --------------------

スペースキー  :  カメラロックオンモード開始

---------------------------------------------------------------

Xキー : 回避
Eキー : 攻撃
Qキー : 必殺技ゲージがたまったら必殺技が発動
Cキー : チャージ強攻撃
敵の攻撃が来るときに回避ボタンを押したらジャスト回避が発動できます。
